# NEP Skills

Fuente única de las skills que ejecuta la rutina de nube "Boletin diario Nada Está Perdido".

- `skills/boletin-diario-nep/` — boletín diario (monitoreo + correo HTML de marca).
- `skills/guiones-reels-nep/` — guiones de reels "Alza la Idea".

## Cómo se usa
La rutina de nube clona este repo en cada corrida y sigue estos SKILL.md.
**Para mejorar una skill: edita el archivo, haz commit y push. La próxima corrida usa la última versión.** No hay que tocar el prompt de la rutina.
